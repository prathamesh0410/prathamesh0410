### 🚀 Featured Project: **FinSight-RAG**

> **Banking Document Intelligence RAG System** — Production-grade Retrieval-Augmented Generation for financial documents

<p align="center">
  <img src="https://img.shields.io/badge/Status-In%20Development-FF6B6B?style=for-the-badge&logo=github" />
  <img src="https://img.shields.io/badge/RAG-LangChain-00D4AA?style=for-the-badge&logo=langchain" />
  <img src="https://img.shields.io/badge/Vector%20DB-ChromaDB-8B5CF6?style=for-the-badge" />
  <img src="https://img.shields.io/badge/LLM-OpenAI%2FAnthropic-00D4AA?style=for-the-badge" />
  <img src="https://img.shields.io/badge/API-FastAPI-009688?style=for-the-badge&logo=fastapi" />
  <img src="https://img.shields.io/badge/DB-PostgreSQL-336791?style=for-the-badge&logo=postgresql" />
  <img src="https://img.shields.io/badge/Deploy-Docker-2496ED?style=for-the-badge&logo=docker" />
</p>

**Architecture Highlights:**
- 🔍 **Hybrid Search**: Dense (embeddings) + Sparse (BM25/FTS) retrieval with reciprocal rank fusion
- 📄 **Document Pipeline**: PDF → Chunking → Metadata Extraction → Embeddings → Vector Store
- 💬 **Cited Answers**: Every response includes source citations with page references
- ⚡ **Streaming**: Real-time token streaming via Server-Sent Events
- 📊 **Evaluation**: RAGAS metrics (faithfulness, answer relevance, context precision)
- 🔒 **Security**: JWT auth, rate limiting, input validation, audit logging

**Tech Stack:** `FastAPI` `LangChain` `ChromaDB` `PostgreSQL` `Redis` `Celery` `Docker` `Streamlit` `pytest` `GitHub Actions`
